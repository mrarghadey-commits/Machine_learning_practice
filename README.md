# Machine Learning Practice

A collection of Jupyter Notebooks demonstrating various machine learning algorithms and deep learning models implemented from scratch or using standard python libraries.

## 📁 Repository Structure

* **`ANN.ipynb`**: Artificial Neural Network implementation.
* **`KNN.ipynb`**: K-Nearest Neighbors classifier model.
* **`Linear_Regression.ipynb`**: Linear regression modeling and analysis.
* **`Logistic_Regression.ipynb`**: Logistic regression for binary/multiclass classification.
* **`SVM.ipynb`**: Support Vector Machine implementations.
